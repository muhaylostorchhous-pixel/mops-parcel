MOPS PARCEL — ОБНОВЛЕНИЕ СУЩЕСТВУЮЩЕГО ПРОЕКТА

1. Скачайте и распакуйте mops-parcel-project.zip.
2. В существующем репозитории GitHub замените исходники содержимым архива.
   Добавьте ВСЕ новые .py-файлы, templates, static, requirements.txt и configure_telegram.py.
   Старый репозиторий удалять не нужно.
3. НЕ заменяйте свой .env, базу SQLite и папку uploads. Их в архиве нет.
4. На Render выполните Deploy latest commit. При ручной настройке:
   Build Command: pip install -r requirements.txt
   Start Command: gunicorn --workers 1 --threads 4 --timeout 90 app:app
5. DATABASE_PATH и UPLOAD_FOLDER должны указывать на прежние данные.
   При первом запуске обновления база дополняется автоматически; создаётся копия
   базы в соседней папке backups. Старые пароли, заказы и изображения сохраняются.

ENV
Существующие SECRET_KEY, ADMIN_EMAIL, ADMIN_PASSWORD, TELEGRAM_BOT_TOKEN,
TELEGRAM_BOT_USERNAME, TELEGRAM_ADMIN_CHAT_ID и TELEGRAM_WEBHOOK_SECRET сохраните.
UKRAINE_MANAGER_USERNAME=barujka032 (если раньше здесь был другой менеджер — измените).
TELEGRAM_WEBAPP_URL — HTTPS-адрес сайта. На Render можно не заполнять:
используется RENDER_EXTERNAL_URL. На другом хостинге укажите вручную.

БОТ
Если webhook уже работает, менять его адрес не нужно: /telegram/webhook.
Чтобы добавить меню команд и кнопку мини-приложения, один раз выполните
в Render Shell или локально с заполненным .env:
python configure_telegram.py
Секрет webhook — отдельная случайная строка, не токен бота.
Перед получением файлов клиент должен нажать «Подключить Telegram» в профиле,
затем Start в боте. Администратор также должен открыть бота через свой профиль
или указать доступный боту TELEGRAM_ADMIN_CHAT_ID.

ДЛЯ НОВОЙ УСТАНОВКИ НА WINDOWS
Установите Python 3.11+, включив Add Python to PATH.
Скопируйте .env.example в .env, заполните свои данные, затем запустите
RUN_MOPS_PARCEL.bat. Сайт: http://127.0.0.1:5000.
Для входа администратора используйте ADMIN_EMAIL и пароль, заданные при
первом запуске. Изменение ADMIN_PASSWORD после создания аккаунта не сбрасывает
его действующий пароль.

ХРАНЕНИЕ
Фотографии открываются через Telegram файлами. Оригиналы всё ещё сохраняются
на сервере для повторной отправки, вместе с подтверждениями оплаты.
На Render нужен постоянный диск для SQLite и uploads; не меняйте его при обновлении.
Пользовательские адреса и сообщения не переводятся автоматически.
