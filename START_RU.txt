ОБНОВЛЕНИЕ MOPS PARCEL

Для обновления существующего проекта:
1. Распакуйте архив.
2. Замените в своём проекте app.py, добавьте i18n.py и замените папки templates и static.
3. Сохраните свой .env, базу данных и папку uploads.
4. Перезапустите сайт.

Для первого запуска на Windows:
1. Распакуйте архив в отдельную папку.
2. Скопируйте .env.example в .env и заполните SECRET_KEY, ADMIN_EMAIL и ADMIN_PASSWORD.
3. Запустите RUN_MOPS_PARCEL.bat.
4. Откройте http://127.0.0.1:5000.

На Render: замените исходники в GitHub и запустите новый Deploy.
Новые обязательные переменные окружения не нужны.
UKRAINE_MANAGER_USERNAME — необязательный username менеджера по Украине.
Если его не указать, связь с менеджером идёт через администратора @amrbasota.

В архиве нет ваших паролей, .env, заказов и загруженных фотографий.
