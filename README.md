# Mops Parcel

Python/Flask parcel dashboard for UK purchases, intake checks, photo reports, payment requests, shared dispatch tracking, review bonuses, and Telegram alerts.

## Local run

1. Install Python 3.11+.
2. In this folder, run: python -m venv .venv
3. Activate it, then run: pip install -r requirements.txt
4. Copy .env.example to .env and set SECRET_KEY, ADMIN_EMAIL, and ADMIN_PASSWORD.
5. Run: python app.py
6. Open http://127.0.0.1:5000

The first startup creates the admin account from ADMIN_EMAIL and ADMIN_PASSWORD. Admin access is assigned by an explicit database role, never by comparing an email supplied by a visitor.

## Telegram setup

Create a bot with BotFather and configure TELEGRAM_BOT_TOKEN, TELEGRAM_BOT_USERNAME, and TELEGRAM_ADMIN_CHAT_ID.

After deployment, set the webhook. Substitute your Render URL and secret locally; do not commit the bot token:

https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://<YOUR-APP>.onrender.com/telegram/webhook&secret_token=<WEBHOOK_SECRET>

Set the same random secret in TELEGRAM_WEBHOOK_SECRET. Clients register with their Telegram username, click Подключить Telegram in their dashboard, and press Start in the bot. This binds the bot numeric chat ID to their account; a bot cannot initiate a private chat from a username alone.

## GitHub and Render

- Create a new GitHub repository named mops-parcel and push the contents of this folder.
- In Render, create a Blueprint from that repository (render.yaml) or create a Python web service with build command pip install -r requirements.txt and start command gunicorn app:app.
- Add the environment values from .env.example in Render. SECRET_KEY is generated by the Blueprint.
- The Blueprint mounts persistent storage at /var/data for the SQLite database and images. Render persistent disks require a paid web-service plan; without one, local database/uploads can be lost on redeploy.
- Add UK purchase addresses and payment details in the admin panel. Keep live payment details in Render environment settings; they are not committed here.

The app accepts JPG, PNG, and WEBP uploads, capped at 12 MB. Orders begin in В процессе and need an administrator to inspect the purchase screenshot for Shipped. The admin can reject an invalid submission with status Отклонено. A submitted photo report starts the two-day return / extra-photo window. Orders move to the archive when marked Доставлено.

## Tests

Run pytest -q from this folder. tests/test_e2e.py contains ten Flask test-client integration flows for signup approval, explicit admin recognition, image uploads, access control, photo reports, data edits, payment requests, dispatch tracking, archiving, and review bonuses.

## Design and languages

The interface uses a black background, blue neon accents, chrome-style serif titles and smooth transitions. RU / UKR / EN translates the public pages, client account, admin dashboard, statuses, notices, forms and tutorial. The language is saved in a cookie for one year. User-entered names, addresses and messages stay as entered. Database statuses keep their original values, so switching languages does not change order data.

Animations respect the operating system's reduced-motion setting.

Bottom Telegram contacts: administrator @amrbasota and technical support @wrong_cloo. The Ukraine dispatch manager link routes through the administrator by default. To use a separate manager, set the optional UKRAINE_MANAGER_USERNAME environment variable without @.

There are 20 automated integration tests: the 10 original order workflows plus 10 localization, persistence, form-value and contact tests. Run python -m pytest -q. These tests use isolated temporary databases and do not send Telegram messages. They do not replace a visual browser check.
